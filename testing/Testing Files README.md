# livesplit_asl_mgs1
## Testing autosplitter files

* For Emulator (Duckstation mainly) and Master Collection I added 2 new functionalities:

# Weapons row
* When enabled, this allows you to display your weapons inventory
* by adding 2 rows (recommended for Any% runs) or 3 rows (All Bosses / Glitchless)
* using ([ASL Var Viewer](https://github.com/hawkerm/LiveSplit.ASLVarViewer))

# PAL Timer
* When enabled, this displays the remaining time until the PAL Key changes 
* to the desired temperature (Warehouse / Blast Furnace) under the Info section of ASL Var Viewer.
